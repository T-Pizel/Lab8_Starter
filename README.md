## Question 1
- Graceful degradation and service workers are related in the way how they help keep the application/site resiliently stable specifically when there is no internet connection. Like with the service workers, they are able to retrieve requests or resources when there is no internet connection while graceful degradation is the process of building the application so that the application can still function when certain components are not available, like the internet. So overall, both graveful degradation and service workers help an application's status stay stable even during an offline state.
